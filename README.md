# labs

HEIG-VD's in-house replacement for GitHub Classroom. SWITCH edu-ID identity plus a
mandatory linked GitHub account drive class, lab, and group management that
**delegates to GitHub** — a class is a GitHub organization, a group is a GitHub
team, and the app stores only what GitHub can't express.
